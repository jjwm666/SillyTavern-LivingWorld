# Living World · 万象世界引擎

Living World 是一个通用 SillyTavern 大世界扩展。它把角色卡与世界书提供的静态设定，变成拥有自主 NPC、地理路线、势力博弈、可验证骰点和持续事件的动态世界。

它不是固定题材卡，也不是让模型随意改写状态的摘要器。**大模型提出符合人物认知的意图，本地规则内核决定行动能否执行以及最终成败。**

## 核心能力

- **自动推演**：主 AI 回复结束后，后台独立调用一次 API，批量生成核心 NPC 与势力的行动意图；最新世界快照自动注入下一轮上下文。
- **人物自主生活**：核心 NPC 拥有目标、需求、性格、情绪、关系、私人记忆、秘密、日程与多阶段计划。NPC 只能利用自己知道的信息，不会读取全知世界状态。
- **真实地图**：地点通过路线连接，具有距离、危险、资源、繁荣和控制权。移动、调查、扩张和流言传播都受地理约束。
- **势力关系网**：势力两两维护关系、利益、条约与宿怨，可以贸易、结盟、施压、扩张或巩固自身，而不只是对玩家表态。
- **可回放骰子**：所有关键判定由 JavaScript 使用可复现种子完成，保存 d20 原值、加值、难度与结果；大模型无权宣布判定成功。
- **分阶段事件**：冲突与发展事件具有进度、停滞、升级、失败和终局，区域事故与经济变化同样经过本地判定。
- **风声与信息差**：消息沿地图传播、逐轮衰减，公开事实、流言、NPC 私人认知与秘密分开保存。
- **分层规模**：重要人物逐人推演，背景人口按地区聚合结算，避免“一个 NPC 一次 API”的成本爆炸。
- **玩家影响力**：四维声誉（声望、威信、恶名、人情）、财富与收支账本；交易、求助、谋划等玩家行动同样经过本地骰点判定。
- **天气与地理**：每个区域具有天气强度，影响移动难度、事件判定、地区物价、风声传播与背景人口结算。
- **主动剧情与转折**：NPC 会在幕后生活并主动来找玩家，形成带到期淘汰的剧情钩子；骰出大失败时内核自动生成转折（恶化或机遇），剧情不再依赖玩家推动。
- **多级地图**：大区域可逐层下钻到次级与再次级区域（最多三层），支持同层路线与面包屑导航。
- **可控推演节奏**：可设置每 X 次回复推演一次，以及 -10 至 +10 的全局骰点修正；修正构成写入每次判定，便于复现。
- **保留与消散**：事件支持收藏保留，未收藏事件按保留轮数自动归档；风声沿地图传播、逐轮衰减。
- **完整面板**：总览、玩家、人物、地图、势力、事件、骰点、设置八个视图，支持深色/白天双主题、导出与导入存档。
- **灵活入口**：悬浮球可拖动、缩放与隐藏；酒馆“扩展设置”菜单内置“万象世界引擎”入口，隐藏悬浮球后依然可以打开面板。
- **世界编辑器**：设置页提供世界 JSON 编辑器，可直接修改世界内容并保存。
- **提示词与预设**：内置四种世界预设，可自定义初始化提示词、每轮推演提示词与后台专用破限词，并支持自定义预设的新建与删除，不修改酒馆全局预设。
- **会话安全**：按聊天隔离存档；生成前保存基线，Swipe、重 roll、删楼层和切聊天时避免重复推演与串档。

## 安装

### 方式一：通过 GitHub 安装

在 SillyTavern 的“扩展 → 安装扩展”中填写：

```text
https://github.com/jjwm666/SillyTavern-LivingWorld
```

### 方式二：下载 Release

1. 打开 [Releases](https://github.com/jjwm666/SillyTavern-LivingWorld/releases)。
2. 下载最新 `LivingWorld-v*.zip`。
3. 解压为 `LivingWorld`，放入当前用户的 `data/<user-handle>/extensions/` 或酒馆第三方扩展目录。
4. 重启或刷新 SillyTavern，在扩展管理页启用 Living World。

不需要执行 `npm install`，发布包已经包含全部运行文件。

## 快速开始

1. 打开一张角色卡或大世界卡，点击右下角悬浮球（也可从“扩展设置”菜单中的“万象世界引擎”进入）。
2. 在“设置”选择后台 API：直接使用酒馆当前连接，或配置独立 OpenAI 兼容接口。
3. 点击“从当前卡初始化世界”。插件会将当前角色描述、场景与近期聊天整理为地图、势力和核心 NPC。
4. 返回聊天正常扮演。每次主 AI 回复完成后，世界自动推进一轮；无需输入“推演世界”。
5. 在面板查看人物计划、地图变化、势力关系与骰点回放。

世界只在对话轮次后推进。插件不会在酒馆页面关闭时运行，也不会按现实时间持续消耗 API。

## 提示词与预设

在“设置 → 提示词与预设”中可选择通用均衡、权谋与势力斗争、探索与区域危机、群像与自主生活。点击“载入预设”后，可继续编辑初始化与每轮推演提示词，再点击“保存设置”；也可以将当前编辑“另存为”自定义预设或删除自定义预设。

- **初始化提示词**：只在从角色卡建立世界时使用。
- **每轮推演提示词**：只在回复后的世界推演时使用。
- **自定义破限词**：同时附加到上述两类后台请求，是否被接受取决于所选模型。

这些指令不会写入聊天记录、世界快照或导出的世界文件，也不会替换酒馆主 AI 的预设。

## 后台 API

### 酒馆当前连接

使用 `SillyTavern.getContext().generateRaw()` 发起独立后台生成，不污染聊天记录。适合快速开始。

### 独立 OpenAI 兼容接口

填写 Base URL、API Key 和模型名。点击“拉取模型列表”会请求 `/models` 验证连通性并自动填入模型名下拉框；点击“测试连接”会真实生成一次 JSON 验证完整链路。插件请求 `/chat/completions`，要求模型能够遵循 JSON 输出提示。API Key 保存在酒馆扩展设置中，不会写入世界存档、聊天注入或导出的世界文件。

世界推演进行中时，可点击面板顶部的停止按钮或设置页的“取消后台推演”立即中止；推演完成、失败或被取消时，酒馆会弹出全局通知，无需保持面板打开。

## 项目结构

```text
manifest.json                 酒馆扩展清单
index.js                      酒馆入口与生命周期
style.css                     完整界面样式
src/engine/                   可测试的本地模拟内核
src/integration/              API、存储、上下文与会话集成
src/ui/                       面板和 SVG 可视化
demo/                         不依赖酒馆的界面演示
scripts/                      检查、构建和演示服务器
tests/                        Node 单元测试
docs/                         架构与使用说明
.github/workflows/            自动测试与 Release 打包
```

## 本地开发

```bash
npm test
npm run check
npm run build
npm run demo
```

演示服务器默认位于 `http://127.0.0.1:4173`。开发演示只读取示例世界，不连接 API，也不会安装到本地酒馆。

## 边界

- 首版聚焦“数十名核心 NPC 精细模拟＋地区背景人口聚合模拟”，不是为每个背景居民建立独立大模型 Agent。
- 自动生成结果仍取决于模型质量；规则内核会校验行动与数值，但无法保证所有文本都符合用户设定。
- 重 roll 能恢复本轮生成前的世界基线；对非常早期楼层进行复杂编辑后，建议导出存档并重新初始化或从备份恢复。
- 酒馆内部 API 可能随版本变化，集成层集中在 `src/integration/`，模拟内核不依赖酒馆。
